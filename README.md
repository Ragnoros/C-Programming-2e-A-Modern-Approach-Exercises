# C: A Modern Approach (2nd Edition) Exercises

This repository contains my personal solutions to the programming exercises from the book "C: A Modern Approach, 2nd Edition" by K. N. King.

I am using this project to learn the C programming language and practice its concepts.

I limit myself to what is currently being taught. An example would be the conditional chapter 05 where if statements are introduced. The solutions to some of the projects at the end are very tedious and convoluted with if statements and I know a loop would be beneficial from experience with other langauges, however loops get introduced in chapter 06.

## Structure

- **test.c**: General Purpose testing file
- **/chapter_02/**: Solutions for Chapter 2
- **/chapter_03/**: Solutions for Chapter 3
- **/chapter_04/**: Solutions for Chapter 4
- **/chapter_05/**: Solutions for Chapter 5
- **/chapter_06/**: Solutions for Chapter 6
